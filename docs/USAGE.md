# Использование

[Главная](../README.md) · [Параметры](PARAMETERS.md) · [Решение проблем](TROUBLESHOOTING.md)

## Первый запуск

1. Запустите монитор и внешний источник AIDA64/LHM; для FPS также RTSS и игру.
2. В **⚙ → Подключить датчики** выберите источник и нажмите **Применить**.
3. На вкладке **Датчики панели** назначьте показатели. Списки обновляются автоматически; выбранный пункт не должен сбрасываться при обновлении.
4. Проверьте обзор, затем откройте **⚙ → Настройки** для языка, названий и интервалов.

**LIVE** означает локальный рабочий режим, не обязательно наличие всех датчиков. **DEMO** — синтетические показания для демонстрации. Статус источника и ошибки смотрите внизу окна и в диагностике.

## Разделы

### Обзор ресурсов

- FPS и имя приложения RTSS, если доступно.
- Полоса CPU: название, основная температура, число ядер/потоков. Ниже история загрузки и карточки частоты, мощности, загрузки, вентилятора.
- Полоса GPU: название/основная температура слева, **температура памяти GPU** справа. Это не Hotspot.
- Полоса SYS/материнской платы: память и ресурсы, температура платы справа. Пользовательское имя платы заменяет SYS.
- RAM/VRAM, сеть, свободное место на дисках, собственные карточки.

### Температуры

Основные температурные карточки и подробная таблица: текущее значение, минимум/максимум за текущий сеанс, статус относительно пользовательского порога и источник. Минимумы/максимумы не являются аппаратными пределами и не сохраняются как история прошлых запусков.

### Все датчики

Сырые опубликованные датчики, включая те, для которых нет отдельной стандартной карточки. Здесь может присутствовать GPU Hotspot: он не заменяет температуру видеопамяти. Лимиты накопителей не считаются текущей температурой.

## Команды шестерёнки

| Команда | Действие |
|---|---|
| Разделы | Выбор обзора, температур или полного списка. |
| Пауза / Продолжить | Замораживает/возобновляет отображение и историю. Фоновый сборщик может продолжать работу; это не отключение внешнего источника. |
| Экспорт JSON | Сохраняет текущие показатели и графическую историю в выбранный файл. На паузе это сохранённый отображаемый снимок. |
| Подключить датчики | Источник, назначения, FPS-диагностика и отчёт. |
| Панель / датчики | Выбор источников, названия, скрытие и свои карточки. |
| Настройки | Язык, стиль, имена, интервалы, история, порог, окно и автозапуск. |
| Полный экран | Переключает безрамочный полный экран. |
| Компактно | Меняет плотность/размер элементов; не меняет сами данные. |

## Настройка карточек

**⚙ → Панель / датчики**:

1. Выберите источник из списка совместимых по типу, устройству и единице датчиков.
2. При желании задайте подпись или отметьте **Скрыть**. Пустая подпись возвращает стандартное название.
3. Через **+ Своя карточка** добавьте дополнительный числовой датчик. Максимум — 128; удаление карточки снова разрешает добавление.
4. Нажмите **Сохранить**. **Отмена** не применяет черновые правки. **Сбросить панель** возвращает стандартные назначения и убирает свои карточки, но не сбрасывает язык/автозапуск и прочие настройки.

**⚙ → Подключить датчики → Датчики панели** меняет те же назначения; здесь кнопка **Применить**. Чтобы изменить название/скрытие или создать карточку, используйте окно **Панель / датчики**.

Если выбранный ID исчез или несовместим, значение — **«—»**. Автоматической подмены другим датчиком нет. Для автоматического выбора явно выберите **Авто / стандартный источник**.

## Окно и трей

- **F11** — полный экран, **Escape** — обычное окно, **Space** — пауза.
- В обычном режиме перемещайте окно за название, часы, версию, строку LIVE/DEMO или свободную шапку. Кнопки, поля и данные не служат областью перетаскивания.
- Положение/размер сохраняются автоматически через 400 мс после изменения и при закрытии. При отключении монитора окно возвращается в видимую область.
- Если закрыть в полном экране, следующий запуск восстановит обычное положение/прежнее развёрнутое состояние, без автоматического полноэкранного захвата.
- В Windows при доступном системном трее отдельная кнопка приложения на панели задач скрыта, но окно остаётся видимым. Если трей недоступен, сохраняется обычное окно с панелью задач.
- Нажмите значок трея или выберите **Показать окно**, чтобы поднять приложение. Контекстное меню трея: показать, пауза, настройки, выход.
- **Крестик окна завершает приложение**, а не просто прячет его в трей.

## Стиль и персонажи

В **⚙ → Настройки → Стиль интерфейса** выберите тему, персонажа и переключатели. **Применить стиль** сохраняет стиль независимо от общего окна настроек; его последующая отмена не откатывает уже применённый стиль.

Портреты/эффекты показываются в свободных областях и скрываются, если места недостаточно (в том числе на узком окне). Они не накладываются на графики. Анимация отключается отдельным флажком; выключение только эффектов не обязательно выключает GIF.

## Автозапуск

В готовом Windows EXE: **⚙ → Настройки → Запускать вместе с Windows → Сохранить**. По умолчанию выключен. Программа открывается после входа текущего пользователя с видимым окном и треем, а не до экрана входа.

Монитор не запускает AIDA64/LHM/RTSS автоматически: их автозапуск настройте отдельно. После переноса EXE повторно сохраните включённый автозапуск из новой папки.

## Экспорт и конфиденциальность

JSON/диагностика могут содержать имена устройств, hostname, значения и выбранные ID. Перед публикацией просмотрите файл и удалите личные сведения. Пароль LHM не сохраняется в пользовательских настройках. Не публикуйте пароли, коды доступа или полные необработанные отчёты, если в них есть личные данные.
