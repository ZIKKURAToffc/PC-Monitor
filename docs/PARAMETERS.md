### Реальная частота обновления

- Системный цикл CPU/RAM/сеть: примерно **250 мс**, без гарантии реального времени.
- RTSS-метаданные приложения: примерно **500 мс**.
- NVIDIA через nvidia-smi: не чаще **1 секунды**; сама команда может занимать больше времени.
- WMI: не чаще **2 секунд**. При неуспешном подключении также применяется замедление повторов.
- LHM/AIDA64 публикуют данные в своём темпе: быстрый опрос может многократно читать один снимок.
- Живые подписи списков «Датчики панели» перерисовываются примерно каждые **250 мс** из фонового снимка; это не отдельный аппаратный запрос.

Слишком быстрый опрос может увеличить нагрузку без новых показаний. Начните с 500–1000 мс и проверьте фактический интервал источника.

## Подключение: ⚙ → Подключить датчики → Подключение

| Параметр | Значения / стандарт | Назначение |
|---|---|---|
| Источник | **AIDA64 Shared Memory** | Локальное чтение экспорта AIDA64; порт/пароль не используются. |
| Источник: LHM HTTP → WMI | Режим Auto | Сначала HTTP; при неудаче WMI для совместимых старых LHM. |
| Источник: LHM только HTTP | Новые версии, в том числе 0.9.5+ | Локальный `127.0.0.1:<порт>/data.json`. |
| Источник: LHM только WMI | Старые версии | Namespace LibreHardwareMonitor в Windows; в новых LHM может отсутствовать. |
| Порт локального LHM | 1–65535; **8085** | Порт сервера LHM, не TCP-порт самой программы. |
| Имя пользователя LHM | Текст; пусто | Для включённой Authentication. Может сохраняться в настройках. |
| Пароль LHM | Пусто | Только текущий сеанс; не сохраняется. Не нужен AIDA64. |

**Применить** сохраняет режим и назначения, затем ожидается фоновый опрос. **Обновить список** обновляет доступный перечень; **Копировать диагностику** копирует локальный отчёт. **Запустить AIDA64/LHM** запускает выбранный EXE внешней программы; при первом выборе нужно указать его файл. **Официальная инструкция** открывает страницу выбранного источника в браузере. **Закрыть** закрывает окно.

## Назначения стандартных карточек

Для всех: **Авто** либо явный ID совместимого датчика. Выбранный недоступный ID не подменяется автоматически. Названия/скрытие — в **Панель / датчики**; источник можно менять и во вкладке **Датчики панели**.

| Карточка | Единица | Значение / допустимое назначение |
|---|---|---|
| FPS | FPS | Опубликованная частота кадров, обычно AIDA64 SRTSSFPS. Не оценка по GPU. |
| Температура CPU | °C | CPU Package/подходящий CPU-температурный источник. Не GPU/диск/плата. |
| Частота CPU | MHz | Частота ядер/подходящее среднее. Не Bus/Fabric/RAM. Эффективная/ОС-частота отмечается отдельно. |
| Загрузка CPU | % | Общая загрузка CPU; ОС либо подходящий общий Load. |
| Мощность CPU | W | Опубликованная мощность CPU, не TDP (%). |
| Вентилятор CPU | RPM | Подходящий CPU/CPU OPT. Безымянный Fan #1 не считается CPU автоматически. |
| Температура GPU | °C | Основная температура ядра GPU, не Hotspot и не память. |
| Частота GPU | MHz | Частота графического ядра, не видеопамяти. |
| Загрузка GPU | % | Загрузка графического ядра, не memory controller/video engine. |
| Мощность GPU | W | Опубликованная мощность GPU. |
| Вентилятор GPU | RPM | Обороты вентилятора GPU; 0 может быть нормальным режимом Fan Stop. Не PWM (%). |
| Температура памяти GPU | °C | GPU Memory/Memory Junction. Выводится справа в GPU-полосе. |
| Плата | °C | Motherboard/System/подходящий датчик платы, не CPU Package. |
| Диск Max | °C | В авто — максимальная подходящая температура накопителей; явный выбор — выбранный источник. Firmware Warning/Critical limits исключаются. |
| RAM занято | GiB | Занятая оперативная память. |
| RAM доступно | GiB | Доступная оперативная память. |
| Загрузка RAM | % | Процент занятой оперативной памяти. |
| VRAM занято | GiB | Использование видеопамяти из совместимого источника/резерва драйвера. |
| VRAM свободно | GiB | Свободная видеопамять; при наличии total/used может вычисляться их разность. |
| Отправка сети | KiB/s | Скорость отправки суммарных счётчиков ОС/совместимого источника, не мегабиты. |
| Загрузка сети | KiB/s | Скорость получения, не отправки. |

**GiB = 1024³ байт**, **KiB = 1024 байта**. Частота в MHz: 3600 MHz = 3,6 GHz. Отображаемые значения зависят от метода источника и не обязаны полностью совпадать с другим монитором.

CPU Core Max и GPU Hotspot не являются отдельными настраиваемыми карточками панели. Сырые соответствующие датчики могут присутствовать в полном списке. GPU Hotspot не подставляется вместо температуры памяти.

## Свои карточки

- До **128** числовых карточек.
- **Источник:** явный опубликованный ID; нет фиксированной CPU/GPU-роли.
- **Название:** до 80 символов; пользовательский текст отображается буквально, без HTML.
- **Единица:** берётся из выбранного источника; при его последующей замене требуется совместимость.
- **Удалить карточку:** убирает её из черновика; итог сохраняется кнопкой **Сохранить**.
- **Сбросить панель:** стандартная панель без своих карточек/явных назначений.

## Автоматические поля и хранение

- Часы, дата, UTC-смещение/часовой пояс следуют ОС. Отдельного ручного выбора зоны нет.
- Положение/размер и развёрнутое состояние сохраняются автоматически; при недоступном мониторе корректируются в видимую область.
- Компактный режим по умолчанию включён; полный экран при старте не включается автоматически.
- Минимумы/максимумы температур — текущий сеанс; uptime — время работы ОС, не время работы самого монитора.
- Настройки: QSettings `Zikkurat/DesktopMonitor`; на Windows стандартно `HKEY_CURRENT_USER\Software\Zikkurat\DesktopMonitor`. Старое имя пространства сохранено для совместимости.
- Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение **PC Monitor**, путь текущего EXE в кавычках. Не включается при сборке автоматически.
- Ошибки Python: `%LOCALAPPDATA%\PC-Monitor\logs\errors.log`, резервно `PC-Monitor-logs` в TEMP. Ротация с двумя резервными файлами; никакой отправки в интернет.

## Параметры командной строки

Для готового EXE либо `python desktop.py`:

| Аргумент | Действие |
|---|---|
| Без аргументов | Обычный LIVE-режим. |
| `--demo` | Синтетическая демонстрация; не реальные датчики. |
| `--tab overview` | Обзор ресурсов при старте; стандарт. |
| `--tab temperatures` | Раздел температур при старте. |
| `--screenshot "путь.png"` | Одноразовый снимок окна примерно после 1,8 секунды и завершение; служебный режим, не непрерывная запись. |
| `--help` | Справка аргументов Python/консольного запуска; windowed EXE может не показывать консоль. |

Для сборки: `build_windows.bat --keep-sources` не удаляет source-папку. Для ярлыка: `create_shortcut.bat "D:\Apps\PC-Monitor.exe"` использует явный путь. Без аргумента — EXE в корне диска проекта.
