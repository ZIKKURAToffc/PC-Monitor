# Проверка PC Monitor Desktop 2.3.34

Команда: `QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests`.

**372 теста проходят.**

## Сохранённые проверки

- LHM HTTP/WMI, локализованные числовые значения, SSD-пороги и корректная частота CPU;
- разбор AIDA64 Shared Memory, системные строки, FPS 0/число/N/A/отсутствие;
- совместимость единиц, ручные назначения без stale-value fallback, свои карточки и сохранение настроек;
- исходная компоновка CPU/GPU/SYS, заполнение высоты, компактность, температура платы;
- единый реальный QFont всех подписей бирюзовых полос в обоих режимах;
- названия оборудования, локализация, отсутствие HTML-интерпретации, длинные подписи;
- шестерёнка без красной рамки, управление меню, отсутствие номеров секций;
- диагностика FPS и корректная подпись выбранного источника.
