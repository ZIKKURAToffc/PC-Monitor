# PC Monitor 2.3.34

Локальный мониторинг ПК для Windows 10/11 x64. Разработчик — **ZIKKURAT**.

## Возможности

CPU/GPU, температуры, RAM/VRAM, сеть и диски; FPS через подходящий источник AIDA64/RTSS; настраиваемые карточки, три языка, десять тем и опциональные аниме GIF/эффекты. Окно с треем, безрамочный полный экран, Topmost, сохранение положения и добровольный автозапуск.

## Исправления 2.3.34

Устойчивость к повреждённым настройкам/карточкам и временным ошибкам ОС; защита гонок источников; освобождение закрытых диалогов; числовая валидация; SHA-256 копии EXE; защита удаления source junction; локальный журнал Python-ошибок; общая версия GUI/CLI; plain-text подписи; исправление пустого ID часового пояса.

## Установка

Если автор прикрепил **PC-Monitor.exe**, скачайте его, поместите в постоянную папку и запустите. Python не нужен. **Source code.zip** — исходники, для них требуется сборка.

При сборке `build_windows.bat` EXE устанавливается в `X:\PC-Monitor`, создаётся ярлык. **После успешной обычной сборки исходная папка полностью удаляется**. ZIP храните вне неё; для разработки/Git используйте `build_windows.bat --keep-sources`.

AIDA64/LHM/RTSS/драйверы устанавливаются отдельно. Наличие датчиков и совместимость FPS с играми зависят от внешнего источника/оборудования. Программа не обходит античит и не отправляет телеметрию.
