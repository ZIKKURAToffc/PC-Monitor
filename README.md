# PC Monitor

**2.3.34 · Windows 10/11 x64 · Разработчик: ZIKKURAT**

Локальный мониторинг CPU, GPU, температур, RAM/VRAM, сети, дисков и FPS. Нативный интерфейс PySide6: русский, украинский и английский языки, настраиваемые карточки, 10 тем и GIF-персонажи. Программа не отправляет телеметрию и не управляет разгоном или вентиляторами.

> **Важно:** обычный `build_windows.bat` после успешной установки EXE **полностью удаляет распакованную папку исходников**. Архивы и личные файлы храните вне неё. Для Git-клона/разработки используйте **`build_windows.bat --keep-sources`**.

## Быстрый старт

### Готовый EXE

1. Откройте **Releases** этого репозитория и скачайте приложенный автором `PC-Monitor.exe`, если он опубликован. GitHub **Source code (zip)** содержит исходники, не установщик.
2. Сохраните EXE в постоянную папку, например `D:\PC-Monitor\PC-Monitor.exe`, и запустите. Python для готового EXE не нужен.
3. В **⚙ → Подключить датчики** настройте AIDA64 либо LHM.
4. Для FPS дополнительно настройте RTSS и экспорт FPS в AIDA64.

### Сборка из исходников

1. Установите **Python 3.10+ x64** с доступом из PATH; рекомендован проверенный Python 3.13.
2. Распакуйте исходники в отдельную папку, например `D:\Downloads\pc-monitor-desktop-v2.3.34`. **Не распаковывайте прямо в `D:\PC-Monitor`: это папка назначения EXE.**
3. Запустите **build_windows.bat**. Если проект нужно сохранить, выполните **`build_windows.bat --keep-sources`** из терминала.
4. EXE появится в **`X:\PC-Monitor\PC-Monitor.exe`**, где X — диск проекта. Создаётся ярлык; временная среда сборки очищается.

При обычной успешной сборке исходники удаляются. При ошибке компиляции/копирования они остаются; при блокировке удаления выводится предупреждение. Интернет нужен для установки зависимостей при сборке, но не для локального чтения датчиков.

## Управление и возможности

Все команды — в меню **⚙**. **F11** — полный экран, **Escape** — выход из него, **Space** — пауза/продолжение. Окно перемещается за шапку и запоминает положение/размер.

- Частота, загрузка, мощность, температуры и вентиляторы CPU/GPU при наличии источника.
- Температура памяти GPU и платы, история загрузки, подробные таблицы датчиков.
- Выбор источников, переименование и скрытие карточек; до 128 своих карточек.
- Имя приложения RTSS при доступных метаданных; FPS не вычисляется из загрузки GPU.
- Видимое окно с треем, режим поверх окон, добровольный автозапуск после входа Windows.
- Экспорт JSON, локальная диагностика; отключаемые анимация, персонажи и эффекты.

## Ограничения

AIDA64/LHM/RTSS и драйверы не входят в EXE. Наличие датчиков зависит от оборудования и экспорта. **«—» — недоступное значение; 0 — опубликованный ноль.** Частая перерисовка не ускоряет внешний источник. Совместимость RTSS с играми/античитом не гарантируется; приложение само не внедряется в процессы игры.

Проверено **372 автоматическими тестами**. Реальную Windows-компиляцию и живые Windows-источники в среде разработки этого пакета не запускали: перед релизом выполните [Windows-чек-лист](AUDIT-2.3.34.md). Linux используется для проверки исходников; Windows-источники/сборка EXE на нём недоступны.
